# react-native-rn-terminal

a libary to get native shell that can run code on your phone's linux sysytem

## Installation


```sh
npm install react-native-rn-terminal
```


## Usage


```js
import { multiply } from 'react-native-rn-terminal';

// ...

const result = multiply(3, 7);
```
